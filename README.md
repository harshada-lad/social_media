# 🚀 ConnectHub - Social Media Web Application

## 📌 Overview

ConnectHub is a modern web-based social media application that allows users to connect, share posts, and interact with others. Users can upload images or videos, like posts, comment, and manage their profiles with a smooth and responsive interface.

---

## 🎯 Features

* 🔐 User Registration & Login
* 📸 Image & 🎥 Video Upload
* 🏷️ Hashtag Tagging (#tags)
* ❤️ Like System
* 💬 Comment System
* 👤 Profile Management (Name, Bio, Profile Picture)
* 🖼️ Grid View of User Posts
* 🔍 Click-to-View Post Popup (Image/Video + Comments + Tags)
* ⚡ Smooth UI with Animations & AJAX

---

## 🛠️ Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** PHP
* **Database:** MySQL
* **Server:** XAMPP

## ⚙️ Installation & Setup

1. Install XAMPP and start **Apache** & **MySQL**
2. Copy project folder to:

   ```
   C:\xampp\htdocs\
   ```
3. Open **phpMyAdmin**
4. Create database:

   ```
   connecthub
   ```
5. Import tables or run SQL manually
6. Open browser:

   ```
   http://localhost/connecthub
   ```

## 🧠 How It Works

* Users register and log in
* Upload posts (image/video with caption & tags)
* View posts in feed
* Like and comment on posts
* View personal posts in profile grid
* Click post to see full details with comments
